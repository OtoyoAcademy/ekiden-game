レースゲーム

5チーム固定。1〜5人で1台を共有し、空いた枠はCPUが参加。選手の走る順序はゴールまで秘密。

10

計測テスト

標準は10チーム・9区間。通過時刻をミリ秒単位で一覧化。同時通過も発生させて計測を練習できます。

∞

保存と再生

結果・区間タイム・走者配置をブラウザ内に保存。JSON形式でバックアップ・別端末へ移行可能です。

GAME MODE

レースゲームの設定

5チーム・6区間。各チーム3選手が1・2・3区間を分担します。

基本合計 120秒強い応援 −3秒/区間普通の応援 −1秒/区間

① 参加プレイヤーを設定

同じチームは選べません。空きチームはCPUが担当します。

② レースをスタート

選手の担当区間と走る順番は、ゴール後まで非公開。すべてのチームは応援前の合計タイムが同じ120秒です。最後に±0.5秒のわずかな変動を加えます。

シリーズ成績

まだ記録がありません。

出場チーム

チームの色は固定です。太い色のラインと丸印で見分けられます。コース上の丸いアイコンの数字は「現在の区間」です。名前やイラストは「選手・画像」で変更できます。
TIMER TEST MODE

計測テストの設定

駅伝タイマーの通過時刻確認向け。ゲームの応援効果は適用されません。

標準：10チーム × 9区間 ≈ 3分

計測条件

区間タイムは基準値±5秒の範囲でランダムに生成します。計測時は再生速度を「1倍」にすると、実時間と同じ速さです。

計測で確認できること

✓ チームごとの区間通過順序
✓ 各区間の通過時刻と区間タイム
✓ 接戦・追い抜き・同時通過
✓ 保存したレースの条件再現
✓ JSON書き出しによる正解データ共有
CHARACTER EDITOR

選手・画像の登録

ゲーム用5チーム・計測用10チームを設定できます。画像は最大240pxへ縮小して保存します。

画像はサーバーに送信されません。ブラウザのデータを消去すると失われるため、保存レースのJSON書き出しでバックアップしてください。
RACE LIBRARY

保存レース

この端末のブラウザに保存されているレース。JSONを読み込めば別の端末でも再現できます。

保存について

レースと選手イラストはIndexedDBに保存されます（ブラウザが許す容量まで）。固定の保存件数制限はありません。再生は保存時の区間・走者・応援・タイムをそのまま使用します。シリーズの勝敗は再生では加算されません。
